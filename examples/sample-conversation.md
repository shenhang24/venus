# Sample: preserving context in a shared note

All content below is synthetic demonstration material.

User: How should a shared note remain useful after the original conversation ends?

Assistant: Preserve the conclusion, the conditions under which it applies, and a short reference to the discussion that formed it. Put background citations in a separate Reference section.

User: I agree with that method for our shared notes: conclusion, applicable conditions and a separate source reference. It should remain editable, and it must not replace a later explicit instruction.

Assistant: The resulting concept is contextual continuity: a note preserves not only a statement but also why and where it applies. This is a design choice for this workflow, not a universal guarantee of correctness or permanent AI memory.

User: Yes, that describes the conclusion for this workflow.
