# Page tour

Vault lists original Markdown files and preserves source text. AI Knowledge presents retrieved facts and methods with sources. AI Skills presents endorsed methods, scope and limitations. Concept Cloud presents complete discussion themes, endorsement status and an independent Reference section. Each content directory has a separate network using the same records.

Open a record to read, follow a source to Vault, or edit derived content. Import explicitly supplied Markdown through the import dialog. Four networks support rotation, zoom, node focus, relation filtering and content navigation. Demonstration results in the included images are synthetic samples, not live model output.
