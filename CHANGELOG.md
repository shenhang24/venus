# Changes

## 0.4.0 — 2026-10-18

This second public release adds Concept Cloud and aligns four distinct layers throughout generation contracts, persistence, merging and retrieval. Vault originals remain unchanged. Concepts require scoped user endorsement, preserve complete discussion themes and Reference evidence, and support bounded integration. Unresolved questions remain optional. Knowledge reuse has a measured 95% character-bigram Dice boundary. Skills carry endorsed method scope and limitations rather than ungrounded proficiency claims.

Forward concept extraction reuses ongoing source reads and calls. Historical missing-concept backfill waits for the frozen batch and does not regenerate completed knowledge or skills. Human edits, stable IDs and source references are protected. Existing records are not rewritten en masse.

Networks include continuous nested orbits, opt-in edge visibility, local camera focus, bounded motion trails, exterior transfer channels and compact group overlap with local body avoidance. Dense-scene behavior remains subject to documented limits. Concept navigation icons and English sample screenshots are included.

Current classification and relation tables continue saving, but their full-table historical snapshots no longer accumulate. Document history and processing checkpoints remain available. Old history is not deleted automatically.

Validation used targeted synthetic rule and geometry checks, an isolated deploy smoke check and a bounded publication privacy scan. No private library, history, credentials, private tunnel configuration or private Git ancestry is included. Screenshots are actual browser captures of synthetic sample data.
