# Security policy

Venus is an early-stage personal project. Security fixes focus on the latest published version; there is no guaranteed support period, backport policy, or response time. Review the [privacy documentation](docs/PRIVACY.md) and use backups before changing a local installation.

## Reporting a concern

The available project reporting channel is [GitHub Issues](https://github.com/shenhang24/venus/issues/new). This repository does not currently advertise a private security-reporting address or confidential intake channel. Do not assume reports are private, and do not post secrets, private data, weaponized proof-of-concept code, exploit steps, or details that would expose users to immediate harm.

If you can safely report a concern publicly, provide a high-level description, affected version, platform, and impact using synthetic information. If details cannot be shared safely, do not disclose them in an issue; at most ask for a suitable private reporting route without revealing the vulnerability. No confidential channel or reply is guaranteed.

Never attach a private Vault, conversation export, access token, API key, account identifier, or unredacted diagnostic log. Do not test against systems or data you do not own or have permission to test. A report does not require purchasing API access or running paid analysis.

Security settings, private reporting features, and external contact channels are not changed or enabled by this document.
